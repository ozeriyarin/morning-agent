# Tech stack

- **Language / runtime:** TypeScript on Node 20, ESM, strict mode. `npm run brief` is the single entry point.
- **Data sources:** Open-Meteo (weather and geocoding, no key) for Modi'in; RSS/Atom feeds parsed in-process; Google Calendar via the claude.ai connector attached to the routine (hand-off file `input/calendar-<date>.json`); iCloud Calendar via CalDAV; Apple Reminders via an iPhone Shortcut that mails a JSON list to Gmail, copied by the routine into `input/reminders-<date>.json` (CalDAV VTODO as fallback); concept and interview queues as Markdown checklists in the repo.
- **AI:** Anthropic SDK, plus OpenRouter over plain `fetch` for Jev. Decision step behind a `DecisionModel` interface: `HaikuDecisionModel` (claude-haiku-4-5, default) or `JevDecisionModel` (`typesafe/jev-1.13` via the OpenRouter decisions API), switched by `decisionModel` in `config/brief.json` or `--decider`, and A/B-compared on recorded runs with `npm run replay`. Writer: claude-sonnet-5-5 with a cached system prompt and a fixed output schema (structured output).
- **Delivery:** Telegram Bot API over plain HTTPS (`sendMessage` HTML); the inbox reads replies with `getUpdates` and a stored offset.
- **Scheduling:** three Claude Code cloud routines: the brief at 04:00 UTC (07:00 Asia/Jerusalem; shift one hour when DST ends), the hourly inbox 04:00–20:00 UTC, and the Sunday replay at 05:00 UTC. Each checks out this repo, runs the command, and commits what changed. Outbound traffic goes through the sandbox egress proxy (`EnvHttpProxyAgent`, allow-listed hosts).
- **Secrets:** environment variables only (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `MORNING_ANTHROPIC_API_KEY`, `ICLOUD_USERNAME`, `ICLOUD_APP_PASSWORD`, `OPENROUTER_API_KEY`), set in the cloud environment, never committed. `.env` is gitignored; `.env.example` lists the names. Hand-off files under `input/` are never committed.
- **Tests:** Vitest. Pure transforms (feed parsing, decision mapping, brief formatting) unit-tested; API clients behind interfaces with fakes.
- **Records:** `runs/YYYY-MM-DD.json` committed by the routine: items fetched, decisions, model, tokens, cost, latency.
- **Tooling:** Agent OS v3 (standards, product, specs), Claude Code for implementation, ESLint + Prettier.
